# Sidorea Shop: Cloud Infrastructure & Networking Tools

A suite of web-based utilities designed to simplify cloud infrastructure management. This application features:
* A web-based CIDR calculator
* An advanced web-based SSH terminal
* A minimal UI for provisioning AWS EC2 instances

## Architectural Variants

Select one of the deployment architectures below to view its specific documentation and source code:
